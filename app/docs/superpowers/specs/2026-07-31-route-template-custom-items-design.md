# 路线模板新增项点与排序设计

## 目标

在“管理路线模板”的编辑页面中，允许用户新增自定义检查项点，并按照模板需要调整已选项点顺序。新增项点只需输入名称，保存后进入项目库并加入当前模板。

## 方案

- 模板编辑器继续使用现有固定检查项点选择列表。
- 增加“新增检查项”入口。新增项点先保存在当前编辑器的待保存状态，避免新建模板尚未获得模板 ID 时产生孤立数据。
- 增加“已选路线顺序”列表，每个项点提供上移、下移操作；勾选、取消勾选和全选/全不选都同步该顺序。
- 模板保存由仓储层在同一个 IndexedDB 事务内完成：校验名称唯一性、写入新增项点、写入模板。已有巡检记录使用快照，不受模板修改影响。
- 既有“新建巡检”页面继续使用现有自定义项点能力，并复用统一的自定义项点默认内容生成逻辑。

## 验证

- UI 测试覆盖新建模板新增自定义项点并按指定顺序保存。
- UI 测试覆盖已有模板编辑时新增自定义项点。
- 仓储测试覆盖新增项点与模板写入的原子性及重复名称校验。
- 执行相关 Vitest、TypeScript 构建、lint 和生产构建。
