# 可编辑评价说明设计

## 目标

下拉检查内容确认后，系统仍自动生成评价说明；用户可在照片评价区直接补充、修改或替换该说明。巡检复核和 Word 导出均采用用户最终保存的说明。

## 交互

1. 确认检查内容后，未手动修改过的照片组继续显示自动生成的评价说明。
2. 用户点击评价说明并输入时，输入框以当前自动说明为初始内容。
3. 保存评价后，手动文本写入照片组；之后不再被检查内容的自动说明覆盖。
4. 未手动修改的旧记录继续使用自动生成说明，保持现有行为。

## 数据与导出

- 继续使用照片组既有的 `description` 字段保存手动评价说明，并增加可选的 `descriptionManuallyEdited` 标记区分自动与手动说明；不增加数据表。
- 报告模型仅在 `descriptionManuallyEdited` 未设置时使用检查内容自动说明；存在手动说明时，优先使用手动说明。
- 复核页面与检查页面使用同一优先级，避免页面显示与 Word 内容不一致。

## 边界与验证

- 空评价说明仍不允许保存。
- 修改检查下拉内容后，尚未手动编辑的说明会随之更新；已经手动编辑的说明保持不变。
- 增加组件测试和 Word 报告模型测试，验证自动说明、手动覆盖和导出优先级。
