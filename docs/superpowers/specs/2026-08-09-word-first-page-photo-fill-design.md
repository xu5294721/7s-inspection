# Word 首页照片补齐设计

## 目标

解决 Word 报告首页在标题、导语和章节文字之后，只出现一个一图或两图检查项点时底部留白过多的问题。首页应更饱满，但不能因此压缩照片、拆开项点或阻止本来可以同页出现的后续项点。

## 生效范围

- 仅作用于自适应照片排版模式。
- 仅作用于报告首页的第一个有照片检查项点。
- 仅作用于该项点有 1 张或 2 张照片时。
- 三图继续使用 2+1，四图继续使用 2×2；后续页面一律使用现有固定画幅规则。
- 不裁剪照片，继续仅拉伸 DOCX 导出副本；原始照片不受影响。

## 排版规则

1. 先按现有常规画幅计算首页首项：单图 135×90mm，双图每张 78×58mm。
2. 使用当前分页估算器判断紧接的下一个完整项点能否在首页剩余空间放下：
   - 能放下：保持常规画幅，让后续项点继续在首页；
   - 不能放下或不存在后续项点：启用首页补齐。
3. 首页补齐仅增大首项照片高度，不缩小宽度、不超过页面可用高度：
   - 单图宽度最多增至 150mm，高度最多 120mm；
   - 双图保持两列，每张宽度 78mm，高度最多 110mm；
   - 实际高度取首页剩余空间、最大高度和安全余量三者的可用值。
4. 首项文字与照片继续作为一个不可拆分内容块；如果补齐后的内容块无法放入首页，则回退到常规完整项点分页规则，不强行拆分或压缩。

## 验证

- 一图首页且后续项点无法放入时，导出尺寸大于常规单图且不超过上限；
- 两图首页且后续项点无法放入时，两个画幅保持相等并放大；
- 首项后仍能放下下一完整项点时，不启用补齐；
- 三图、四图和非首页项点尺寸不变；
- 用 LibreOffice 渲染实际 DOCX，确认首页更饱满、项点不拆页、照片无缺失。
