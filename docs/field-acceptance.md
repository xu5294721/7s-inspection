记录实际设备型号、Android/Chrome 版本、办公软件版本、测试日期和验收人员。以下项目必须由用户在真实手机或真实办公软件中操作确认，自动化测试不能代替，因此当前全部保持未勾选。

## Android 现场检查

- [ ] 后置摄像头可由“拍照”入口正常调用，拍摄后照片进入当前巡检项点。
- [ ] 相册支持一次多选照片，选择结果和顺序符合现场使用预期。
- [ ] 真实 Android 手机可连续处理 100 张现场照片，进度、失败重试和存储提示正常。
- [ ] 在 360 像素宽手机上，首页、巡检、分类、复核和设置页面文字可读，控件无重叠或横向溢出。
- [ ] 在 412 像素宽手机上，首页、巡检、分类、复核和设置页面文字可读，控件无重叠或横向溢出。
- [ ] Android Chrome 可“添加到主屏幕/安装应用”，从图标启动后为独立窗口。
- [ ] 在线保存巡检草稿后断网重启应用，离线应用壳和草稿均可恢复并继续使用。
- [ ] Android WPS 可打开生成的 DOCX，照片、中文段落、奖励和考核内容显示正常。

## 电脑办公软件检查

- [ ] Windows WPS 可打开生成的 DOCX，分页、表格、照片和落款正常。
- [ ] Microsoft Word 可打开生成的 DOCX，无修复提示，分页、表格、照片和落款正常。
- [ ] 分别生成每行 2 张和每行 3 张照片的文档，实际版式均符合使用要求。
- [ ] 中文正文、人员、金额、标题和中文 `.docx` 文件名在 Android WPS、Windows WPS 和 Microsoft Word 中均正常。

## 数据安全检查

- [ ] 在真实设备导出 ZIP 备份，清除应用数据后恢复，巡检、照片、模板和设置均完整恢复。
