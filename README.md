# 7S 巡检管理

面向现场 7S 日常巡检的移动端工具，用于减少现场拍照后再回家整理巡检通报的工作量。

当前为 `v1.0.0` 初始版本，支持网页/PWA 和 Android APK 两种使用方式。

## 主要功能

- 巡检路线模板：可选择固定项点，也可新建模板、增加自定义项点并排序。
- 现场检查：进入单个项点后拍照或从相册选择照片，填写检查内容和评价说明。
- 三类评价：好的方面、提醒问题、考核问题；考核问题可填写责任人员、金额，并可选择是否转入后续整改追踪。
- 下拉检查标准：提供简洁的固定选项，也支持在“自定义”中输入现场实际情况。
- 巡检草稿：检查过程自动保存，可在历史记录中继续未完成的巡检。
- 通报复核：可修改项点和评价，并在好的方面、提醒问题、考核问题三个分类内分别排序。
- Word 通报：一键生成 `.docx` 文件；没有内容的章节不显示。正文、总体情况和各类问题均按模板设置的字号、首行缩进等格式输出。
- 本地备份：可导出 ZIP 备份并恢复巡检记录、照片、路线模板和设置。
- Android 文件保存：生成的 Word 和 ZIP 备份可保存到手机“下载”目录，便于使用 WPS 或 Word 打开、分享。

## 使用流程

1. 在“巡检”中选择路线模板并开始检查。
2. 逐项拍照，选择检查内容和评价类别，保存评价。
3. 完成检查后进入“通报复核”，核对文字、照片和分类排序。
4. 设置 Word 模板后生成并下载或分享 Word 通报。
5. 定期在“设置 > 备份与存储”导出 ZIP 备份。

## Android 安装

APK 安装包由项目构建生成。将 APK 文件传至 Android 手机后，在“下载”目录中点击安装；如系统提示，请仅对所使用的文件管理器授权“允许安装未知应用”。

安装后，应用可以离线使用。建议首次使用后尽快导出一次 ZIP 备份，并在每次形成重要通报后再次备份。

## 数据说明

巡检记录、照片、路线模板和 Word 设置默认保存于本机。应用不会自动同步到其他手机或电脑。

请勿随意清除应用数据、卸载应用或使用系统清理工具；更换设备前，应先导出 ZIP 备份，并在新设备导入恢复。

## 项目结构

- `app/`：网页、PWA 和 Android Capacitor 工程源码。
- `output/`：本地生成的 APK 文件，不上传到仓库。
- `docs/`：项目设计与开发资料。

## 本地开发

进入 `app` 目录后执行：

```powershell
pnpm install --frozen-lockfile
pnpm test:run
pnpm lint
pnpm build
```

本项目用于内部现场管理，仓库不包含巡检原始材料、照片、Word 通报、备份数据或个人工作资料。
